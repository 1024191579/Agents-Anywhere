# Agents Anywhere 2.1.0

2.1.0 是一次接口更新（MINOR）：管理统计从"按请求重算"改为"按事件记录"，`/api/v2/admin/dashboard/*` 被 `/api/v2/admin/usage/*` 取代。按[版本号规则](../versioning.md)，所有端的版本号统一升到 2.1.0；本文档在安装包构建前只记录接口变化、各端最低配套版本和数据库迁移，安装包记录待发布时补充。

## 接口变化

- 新增 `GET /api/v2/admin/usage/report?from&to&tz` 与 `GET /api/v2/admin/usage/live`，口径见 [Admin Usage API](../api/admin-usage.md)。
- 删除 `GET/PATCH /api/v2/admin/dashboard/settings`、`GET /api/v2/admin/dashboard/overview`、`POST /api/v2/admin/dashboard/snapshots/*`。2.0.x 的 Web / Desktop 看板页面连接 2.1.0 Server 时会收到 404，需要升级客户端。
- 认证依赖 `current_user_id` 现在会记录用户活跃（进程内每用户 5 分钟节流），不再通过 `/auth/me` 单独写 `platform_user_activity`。
- Connector 协议没有变化；`session.turnEnded`、`notice.upsert`、`runtime.error` 通知在 Server 侧额外产生统计事件。
- Runtime 实例状态（`RuntimeInstanceStatus`、`runtime.statusChanged`、`runtime.start` 回复）新增可选 `phase {code, message, retryable?}`，描述非 error 状态内的子步骤（如 `starting` 期间的 `syncing`）。Server 在实例报告 starting phase 时不再重发 `runtime.start`，会话操作得到可重试的 `409 runtime_starting`。老 Connector 不发 `phase`，行为不变。
- Codex Runtime 配置新增 `ipcEnabled`、`ipcDeeplinkHandoff` 两个布尔项（默认开），schema revision 升到 8；旧配置缺省按开处理。

## 各端最低配套版本

| 端 | 最低版本 | 说明 |
| --- | --- | --- |
| Server | 2.1.0 | 提供新的统计接口与 runtime `phase`；需要执行数据库迁移 `v2_42`、`v2_43` |
| Web | 2.1.0 | 新看板页面（概览 / 用户 / 使用量 / 设备与 Runtime / 运行质量）；DSH 同步中显示为进度而非错误 |
| Desktop | 2.1.0 | 同 Web，渲染层同步 |
| Android / iOS | 2.0.3 | 不包含管理统计功能；2.1.0 的 iOS 才会把同步中的 Runtime 显示为进度，并带 Codex IPC 开关文案 |
| Connector / DSH 插件 | 2.0.3 | 2.0.x Connector 不上报 `phase`，与 2.1.0 Server 兼容；Codex IPC 接管需要 2.1.0 Connector |

## 产品变化

- 管理看板重做：按请求所在时区切天，提供 7 / 30 / 90 天预设和自定义范围；新增 WAU / MAU 滚动窗口、新用户留存、按小时分布、按 Runtime 的使用明细、设备与 Runtime 安装情况、回合结果与时长分位、审批等待时长、Runtime 错误等指标，以及"在线设备 / 运行中回合 / 15 分钟内活跃"的实时条。
- Runtime 维度不再写死 Codex / Claude Code / DSH，而是按会话绑定的 Runtime 类型动态统计，显示名来自设备上报的发现结果。
- 统计数据从升级日起按事件累计，不回填历史。
- Codex：Connector 接入 Codex 桌面 App / IDE 插件的 IPC 路由，在 Codex 窗口里打开的线程会被跟随并通过该窗口代为操作（发消息、steer、中断、审批、模型与权限切换、附件），Connector 自己持有的线程也能被 Codex 窗口跟随。新增会话命令 `/open-in-codex-app`（让桌面 App 打开当前线程）与 `/kill-chatgpt`（停掉桌面 App 以释放其写锁）。两项能力可在 Codex Runtime 配置里关闭。细节见 [Codex IPC 接管](../codex-ipc-takeover.md)。
- DSH：同步会话期间 Runtime 显示为"启动中 · 正在同步 DSH 会话…"，不再显示为异常；同步期间发起的会话操作不再打断同步。

## Server 与数据库

2.1.0 的数据库 revision 为 `v2_43`（schema version `2.43`）。`v2_42` 新建 `usage_events`、`usage_inventory_snapshots`，并删除 `dashboard_daily_metrics`、`dashboard_user_daily_facts`、`dashboard_settings`、`platform_user_activity`，旧看板数据不会保留；`v2_43` 给 `device_runtimes` 增加 `phase_json` 列。升级步骤见[升级指南](../upgrading.md)。

新增环境变量（均可省略）：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `AGENT_SERVER_USAGE_RETENTION_DAYS` | `400` | 事件保留天数，`0` 表示不清理 |
| `AGENT_SERVER_USAGE_FLUSH_INTERVAL_SECONDS` | `1` | 事件批量落库的间隔 |
